game brief 
it's a memorey game where players flip cards to match pairs before the timer runs out 



user stories 

1- As a user i want to see the game title when the page loads
2- As a user i want to see instructions on how to play 
3- As a user i want to see all cards face down 
4- As a user i want to click a card to flip it over 
5- As a user i want to flip only two cards at a time 
6- As a user i want matching cards to face up  
7- As a user i want non matching cards to flip back over  
8- As a user i want to see how many moves i have made
9- As a user i want to see the timer when i play 
10- As a user i want to win when all cards match 
11- As a user i want to lose as the timer finishes 
12- As a user i want to see a win or lose message when the game ends
13- As a user i want to click a restart button to play again
14- As a user i want to see all cards for 5 seconds before the game starts
